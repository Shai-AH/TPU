# 64-bit TPU (Logisim)

This project implements a 64-bit Tensor Processing Unit using Logisim Evolution.

## Features

* 16x16 Matrix Multiplication
* Systolic Array Architecture
* Instruction RAM and ROM based PCU

## File

* tpu.circ → Main circuit

## How to run

1. Open in Logisim Evolution
2. Run simulation
